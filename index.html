GT Movies Store

Project Overview

GT Movies Store is a full-stack web application developed with Django. Users can browse a movie catalog, search for movies, create accounts, write and manage reviews, use a shopping cart, purchase movies, and view their previous orders.

The project also includes Django's administrative interface for managing users, movies, reviews, orders, and purchase items.

For the additional project requirement, I extended the review system with inappropriate-review reporting. A logged-in user can report another user's review. Reported reviews are removed from the public movie page but remain stored in the database so an administrator can still inspect them.

Technologies

Python, Django, HTML, CSS, Bootstrap, MySQL, SQLite, Git, GitHub, and PythonAnywhere.

Live Application: Launch GT Movies Store

Features and User Stories

  • About: Users can view information about the Movies Store.
  • Accounts: Users can sign up, log in, and log out.
  • Movies: Users can browse database-backed movie records and open individual movie pages.
  • Search: Users can search for movies by name.
  • Shopping Cart: Users can select movie quantities, add movies to the cart, view the total, and clear the cart.
  • Reviews: Authenticated users can create reviews. Review authors can edit and delete their own reviews.
  • Purchases: Authenticated users can purchase the contents of their cart.
  • Order History: Users can view their previous orders and purchased items.
  • Responsive Interface: Bootstrap is used to adapt the application to different screen sizes.
  • Deployment: The application is publicly deployed using PythonAnywhere.
  • Administration: Django Admin provides management of users, movies, reviews, orders, and items.
  • Review Reporting: Authenticated users can report reviews created by another user. Reported reviews disappear from the public site while remaining available to administrators.

Development Process

I developed GT Movies Store by following Django 5 for the Impatient, Second Edition. The application grew chapter by chapter, with each part introducing another Django concept.

Chapters 1–2 — Django Setup and Project Structure

I began by creating the Django project and learning the Model-View-Template architecture. I created the Home application and built the Home and About pages. This introduced me to project URLs, application URLs, views, and templates.

Chapter 3 — Base Template and Styling

I created a reusable base.html template and added Bootstrap, custom CSS, static images, a navigation bar, and a footer.

I also debugged several formatting problems caused by Bootstrap links, CSS classes, and Django template expressions being accidentally split across lines.

Chapter 4 — Movies Application

I created the Movies application and initially used a Python list containing movie information. I built the movie catalog and individual movie pages before introducing database models.

Chapters 5–6 — Models and QuerySets

I created the Movie model, learned how Django migrations work, installed Pillow for image uploads, created a superuser, and registered movies in Django Admin.

I then replaced the temporary movie data with database-backed QuerySets and implemented movie search using name__icontains.

Chapter 7 — Database Configuration

I configured MySQL for my local development environment and learned how Django can work with different database engines.

I also customized Django Admin so movies could be ordered and searched by name. During this stage, I debugged database connection and database-creation problems.

Chapter 8 — Authentication

I created the Accounts application and implemented signup, login, and logout using Django's built-in authentication system.

I customized the signup form, validation errors, and navigation bar so the interface changes depending on the user's authentication state.

Chapter 9 — Reviews

I created the Review model and implemented Create, Read, Update, and Delete operations.

I added authorization checks so users can only edit or delete reviews that belong to them.

Chapter 10 — Shopping Cart

I created the Cart application and learned how Django sessions can preserve data between requests. The cart stores movie IDs and quantities inside the user's session.

I implemented adding movies, displaying quantities, calculating totals, and clearing the cart.

Chapters 11–12 — Orders and Purchases

I created Order and Item models to permanently store purchase information.

Completing a purchase creates an Order and its Item records, clears the session cart, and makes the purchase available through the user's Orders page.

Chapter 13 — Deployment

I used Git and GitHub to transfer the project to PythonAnywhere and configured the virtual environment, WSGI application, database migrations, allowed hosts, static files, and media files.

My local development environment used MySQL. My PythonAnywhere environment uses SQLite because of the database options available with the hosting account.

Deployment also required me to work through GitHub authentication, repository access, static-file collection, and PythonAnywhere configuration.

Additional Requirement — Review Reporting

After completing the functionality from the textbook, I implemented the review-reporting requirement.

I added a reported field to the Review model and created a reporting URL, view, and form. The movie page filters reported reviews from public display without deleting them from the database.

I also added authorization so users cannot report their own reviews.

What I Learned

Building the application incrementally helped me understand how Django's URLs, views, templates, models, migrations, authentication, sessions, and deployment work together.

I also learned that debugging is a major part of web development. During the project I worked through template syntax issues, database errors, migrations, authentication issues, GitHub authentication, static-file configuration, and differences between local and deployed environments.
