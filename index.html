GT Movies Store

GT Movies Store is a full-stack web application developed with Django. The application allows users to browse and search for movies, create accounts, write reviews, manage a shopping cart, purchase movies, and view previous orders.

The application also includes an administrative interface for managing application data and a custom review-reporting feature that allows users to report inappropriate reviews.

Technologies: Python, Django, HTML, CSS, Bootstrap, SQLite, Git, GitHub, and PythonAnywhere.

Live Application: Open GT Movies Store

Features and User Stories

The application implements the required Movies Store user stories, including:

  • User Story 1: Users can access an About page containing information about the Movies Store.
  • User Stories 2–3: Users can create accounts, log in, and log out.
  • User Stories 4–5: Users can browse the movie catalog and search for movies by name.
  • User Stories 6–8: Users can add movies to a shopping cart, view the cart, and clear items from it.
  • User Stories 9–13: Authenticated users can create, view, edit, and delete movie reviews while review ownership is enforced.
  • Purchase and Order Stories: Users can purchase the contents of their cart and review their previous orders.
  • Deployment and Interface Stories: The application provides a responsive interface and is deployed publicly using PythonAnywhere.
  • Administrative Stories: Django Admin provides management of users, movies, reviews, orders, and related application data.
  • User Story 21: Authenticated users can report inappropriate reviews written by other users. Reported reviews are hidden from the public movie page while remaining stored in the database for administrative review.

Development Process

I developed GT Movies Store incrementally while learning the Django Model-View-Template architecture. The project began with the basic Django project structure and a Home application. I then created a reusable base template with Bootstrap so that the application shared a consistent responsive navigation bar, content layout, and footer.

The next stage focused on data. I created the Movie model and configured Django's database and administrative interface. The movies application was then updated so movie information came from the database rather than hard-coded Python data. Search functionality was added using Django QuerySets.

I then implemented authentication with Django's user system. Users can sign up, log in, log out, and access functionality that requires authentication. I used Django's authentication decorators and user model to limit certain actions to logged-in users.

The review system introduced database relationships between users, movies, and reviews. Users can create reviews and the application verifies ownership before allowing a review to be edited or deleted.

After the review system, I implemented the shopping cart using Django sessions. Order and Item models were then added so completed purchases could be permanently stored in the database and displayed on the user's order-history page.

One additional requirement was reporting inappropriate reviews. I extended the Review model with a reported field and created a reporting view and URL. When another authenticated user reports a review, the review remains stored for administrative purposes but is excluded from public review queries.

Throughout development I tested the application locally, fixed template, URL, model, migration, and database configuration issues, and used Git for version control. The final application was deployed to PythonAnywhere. The deployed environment uses SQLite and PythonAnywhere's WSGI and static-file configuration.

Development Highlights

  • Designed the application around Django's Model-View-Template architecture.
  • Created separate Home, Movies, Accounts, and Cart applications to keep functionality organized.
  • Implemented relational models for Movies, Reviews, Orders, and Items.
  • Implemented authentication and authorization for user-specific actions.
  • Used Django sessions to implement the shopping cart.
  • Added a custom review-reporting feature beyond the base Movies Store functionality.
  • Used migrations to keep database structure synchronized with Django models.
  • Used Git and GitHub for version control and deployed the application to PythonAnywhere.

  14. Resize the browser or use a mobile-sized window to demonstrate the responsive interface.
